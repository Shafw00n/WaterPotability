Alur Preprocessing & Pembagian Data (Kriteria 2 UTS)

1. Imputasi Nilai Hilang

Ditemukan missing values pada kolom:
• ph: 491 baris
• Sulfate: 781 baris
• Trihalomethanes: 162 baris
Nilai kosong diisi menggunakan nilai median data latih (Median Imputation) agar tahan terhadap outliers.

2. Data Splitting (80:20)

Data dibagi menjadi dua himpunan independen:
• Data Training (80%): {{ "{:,}".format(metrics.dataset.train_count) }} baris untuk melatih model.
• Data Testing (20%): {{ "{:,}".format(metrics.dataset.test_count) }} baris untuk evaluasi performa matriks konfusi murni tanpa kebocoran data.

3. Penskalaan Fitur (Scaling)

Fitur numerik diskalakan menggunakan StandardScaler ($\mu=0, \sigma=1$) khusus untuk pelatihan model Multilayer Perceptron (MLP) agar fungsi aktivasi dan algoritma optimasi bobot (Adam Optimizer) bekerja optimal.
